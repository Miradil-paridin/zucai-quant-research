# 五大联赛历史数据源核验与采集建议

核验日期：2026-07-27（Asia/Shanghai）

## 结论

五大联赛深历史暂时不需要大规模网页爬取。当前最实用的主源是
[Football-Data.co.uk 历史档案](https://www.football-data.co.uk/data.php)：
五大联赛结果可追溯到 1993/94，赔率和主要比赛统计大致从 2000/01 开始，
下载地址稳定且不需要 API key。

项目现有 football-data.org 免费账号适合近期赛果和第二来源核验，但不适合深
历史：2024/25 五大联赛完整请求均返回 HTTP 200，而英超 `season=2015` 的实际
测试返回 HTTP 403。官网也把“10 seasons of history”列在付费 ML Pack 中。

## 已保存证据

- `football-data-co-uk/2024-25`：五大联赛现代完整样本，1,752 场，含赔率与统计
- `football-data-co-uk/1993-94`：五大联赛历史边界样本，1,834 场，仅 7 个有效字段
- `football-data-org/2024-25`：使用现有账号取得的五大联赛完整 API 响应，1,752 场
- `openfootball/2024-25`：CC0 的第二公开来源
- `validate_cross_source.py`：固定哈希、显式球队别名、逐场比分比对
- `cross_source_validation.json`：确定性的机器可读核验结果
- `team_aliases_2024_25.json`：96 支球队的已验证跨源别名

所有原始下载均未改写，并保存了 URL、HTTP 响应头、字节数、SHA-256 和下载时间。

## 来源优先级

### P0：Football-Data.co.uk

直链格式：

```text
https://www.football-data.co.uk/mmz4281/{赛季代码}/{联赛代码}.csv
```

例如：

```text
https://www.football-data.co.uk/mmz4281/2425/E0.csv
https://www.football-data.co.uk/mmz4281/9394/E0.csv
```

五大联赛代码：

| 联赛 | 代码 |
| --- | --- |
| 英超 | `E0` |
| 德甲 | `D1` |
| 意甲 | `I1` |
| 西甲 | `SP1` |
| 法甲 | `F1` |

字段说明以 [notes.txt](https://www.football-data.co.uk/notes.txt) 为准。

优点：

- 实际确认 1993/94 与 2024/25 的五大联赛 URL 全部可下载
- 现代赛季同时有结果、基础比赛统计、早盘/收盘 1X2、大小球和亚洲让球
- 文件小、请求少，适合批量回填

限制：

- 它是二次汇编源，不是各联赛官方数据库，并明确免责声明
- 网站称数据免费用于量化测试/联赛预测，但页脚同时写有 All Rights Reserved，
  未发现标准开放许可；原始文件公开再分发或商业使用前应取得书面许可
- Schema 随赛季变化；1993/94 只有 7 个有效字段，且有空表头和大量填充空行
- 早期只有赛果；不能把不存在的统计和赔率补成零
- 现代 `Time` 没有时区；交叉检查显示大陆联赛文件采用类似英国本地时间的口径
- 意甲从 2018/19 起射门统计口径可能改变
- 原站警告自 2025-07-23 起 Pinnacle 数据可能滞后

### P1：football-data.org

[官方文档](https://docs.football-data.org/general/v4/index.html)说明免费账号限
10 次/分钟。当前账号已实际取得 2024/25 五大联赛完整 1,752 场，并与主 CSV
全场比分逐场一致。

可用于：

- 近期赛程、UTC 开球时间、比赛/球队稳定 ID、比分、状态和裁判
- 主 CSV 的第二来源核验
- 识别 `AWARDED` 等裁定比赛

不应承担：

- 深历史：旧赛季实测受当前套餐限制
- 免费赔率：响应只返回激活 Odds Package 的提示
- 免费高级统计、阵容和事件

### P1：OpenFootball

[OpenFootball football.json](https://github.com/openfootball/football.json)
明确采用 CC0/Public Domain，可自由使用，适合作为赛程和比分的第三来源。

但 2024/25 样本显示它的意甲、西甲最后一轮共 20 场比分为空，并且一场半场比分
错误，因此只能用于校验，不能自动覆盖主源。

### P2：StatsBomb Open Data

[StatsBomb/Hudl Open Data](https://github.com/hudl/open-data)提供高质量事件、
阵容及部分 360 数据，发布分析时要求注明 StatsBomb 并使用其 logo。

当前公开比赛并非五大联赛连续全覆盖：英超、德甲、意甲只有少数选定赛季，
法甲有少数赛季，西甲覆盖相对较多。因此它适合事件模型研究和特征校准，不适合
作为五大联赛基础历史赛果仓库。

## 建议的回填顺序

1. 下载五大联赛 2000/01–2024/25：共 25 个赛季、125 个 CSV，优先获得赛果、
   赔率和可用的比赛统计。
2. 下载 1993/94–1999/00：共 7 个赛季、35 个 CSV，仅作为长期赛果与球队强度
   训练样本。
3. 单独处理 2025/26 和之后的增量；近期结果由 API 交叉核验。
4. 五大联赛全部通过质量门后，再扩展瑞典、挪威、芬兰等联赛。

下载器应串行或低并发、设置清晰 User-Agent、保存 ETag/Last-Modified、支持
条件请求，并在失败时退避；不能对站点进行高并发抓取。

## 入库前强制质量门

1. 原始文件只读保存，记录 URL、时间、HTTP 元数据和 SHA-256。
2. 按表头名称而不是固定列号读取；忽略未命名列和 `Date` 为空的填充行。
3. 缺失值保留 `NULL`，绝不猜测或补零。
4. 校验日期、球队、全场比分、`FTR` 逻辑、重复自然键和合理赛季场次数。
5. 通过版本化球队别名表完成跨源合并；未映射球队进入人工审查队列。
6. `AWARDED/POSTPONED/CANCELLED` 与普通完赛分开保存。
7. 时间按来源口径转换 UTC；不能根据联赛国家直接猜时区。
8. 早盘、收盘赔率分别保存采集语义；回测严格按当时可得时间截断，防止数据泄漏。
9. 每批导入前运行独立审查；存在冲突时保留各源原值和审计状态，不按多数票自动
   决定。
10. 争议字段优先查各联赛或俱乐部官方来源，并记录解决 URL。

## 已发现的真实冲突

- 2024-12-14 Union Berlin–Bochum：场上为 1:1，德国足协最终裁定 Bochum
  2:0 获胜。比分应保存 0:2，并标记为裁定结果；不能生成半场/统计。
- 2025-02-06 Fiorentina–Inter：Football-Data.co.uk 半场为 0:0；
  OpenFootball 和 football-data.org 都错误写成 3:0。Inter 官方比赛中心确认
  半场 0:0、三个进球均在下半场。此例证明两个聚合源可能共享上游错误，不能用
  多数票代替官方核验。

## 何时才使用网页爬取或浏览器控制

仅在公开下载/API 确实缺少字段，并且目标网站条款和 robots 允许时使用。优先抓
官方联赛/俱乐部页面，并仅针对缺失或冲突比赛；每条数据保存页面 URL、抓取时间、
页面快照哈希和解析器版本。

不建议把受登录、验证码、强反爬或许可不清晰的赔率网站作为自动化主源。抓取失败
时应保留“缺失/待核验”，不能由模型补写数据。
