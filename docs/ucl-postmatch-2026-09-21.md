# 欧冠18场赛后事实与复盘（v3）

入口：`/reference?view=dossiers`。当前研究版本：`2026-09-21-v3`。

本次补充了所有18场的UEFA官方全场统计及事件记录。页面将已完赛状态、半场／全场比分、分半场统计、进球与红牌顺序置于首屏，换人及黄牌可展开查看。原有阵容推断移入资料展开区，每场另有基于实际统计和事件的新复盘。

## 已核对的范围

- 18场各16项统计：进球、射门、射正、射偏、被封堵、门框、扑救、角球、越位、控球、黄牌、红牌、犯规、传球尝试、成功传球、传球成功率。每项保留上半场、下半场、全场值；页面优先展示8项常用指标，可切换时段，完整数值保留在接口与数据文件。
- 69次进球、168次换人、70张黄牌、4张红牌，共311条关键事件；不是所有触球或传球事件的总数。
- 396条正式首发保留。新增36份PDF（18份统计表、18份赛后报告）和36份API来源（完赛信息与事件各18份），连同原有资料共113个引用来源。
- 18场复盘均已用统计与事件重写；与之前只有阵容假设的版本分开保存。

## 校验与处理口径

统计表严格检查标题、比赛日期、球队顺序、最终比分；取每行前六列，分别表示两个半场和全场的主客值，排除赛季平均等后续列。检查计数项目两半场相加等于全场、射正／射偏／封堵之和等于总射门、控球合计100%、成功传球不超过尝试。

事件检查比赛ID、完赛标记、日期、比分和唯一ID，按半场、分钟、补时分钟、秒排序。乌龙球计入受益方；比分进程由已确认进球重新累加，不能使用事件接口的`totalScore`作为当时比分，因为该字段可能保存最终比分。进球及罚牌总数再与统计表核对，进球同时校验半场比分。

换人使用主事件人物为离场、次事件人物为入场，并从正式首发开始维护场上名单，验证所有离场者确实在场。罚下教练或非场上人员不减少场上人数。保留接口分钟口径，与正式报告一致，不擅自将分钟数加一。

资料仍全部属于赛后补采；原来的赛前概率档案不改写，也没有增加任何历史命中率样本。

## 本轮仍未提供的内容

所用UEFA统计表不含xG，字段保留`null`，页面明确标注。射门数不能替代xG。伤停仍为35队部分报道、矿工伤停未知；比赛已结束并不会自动公开每名球员缺席的医学原因。新复盘验证的是比赛统计和事件顺序，不声称已经观看并编码全部18场录像，也不把相关性当作战术因果证明。
